# Surviving the Abyss 简体中文汉化补丁 v1.0

适用于 **Surviving the Abyss 1.0.5**（Steam 正版）。

---

## 安装步骤

1. **完全退出游戏**（Steam 里也要退）
2. 解压本压缩包到任意位置（**不要**解压到游戏目录里）
3. **双击 `install.bat`** ⚠️ **不要直接拖拽覆盖游戏文件**
4. 按提示操作（脚本会自动找游戏目录、备份、覆盖）
5. 启动游戏，中文生效

**如果脚本找不到游戏**：手动输入游戏目录，例如：
`D:\STEAM\steamapps\common\Surviving The Abyss`

**如果 `install.bat` 显示乱码**：右键 → 编辑，把 `chcp 65001` 改成 `chcp 936`，保存后再双击。

---

## 卸载 / 还原

安装时自动在 `Surviving the Abyss_Data\_CN_Backup_<时间戳>\` 创建备份。

还原步骤：
1. 关闭游戏
2. 打开备份目录
3. 把 3 个文件 + Localization 目录复制回原位

---

## 已知问题

- **个别生僻汉字显示为空格**：字体图集未包含该字。常见字已全部覆盖，仅极少数冷僻字可能出现此情况。不影响正常游玩。
- **若游戏更新后汉化失效**：重新跑一次 `install.bat`。

## 反馈问题

反馈邮箱：**TransCNReport@163.com**

### 未汉化文本

1. 在有问题的界面**按 F9**（游戏会记录当前显示的所有文本到日志）
2. 关闭游戏
3. 打开日志文件：
   `%USERPROFILE%\AppData\LocalLow\RocketFlair\Surviving the Abyss\Player.log`
4. 用记事本打开，把最后 100 行里以 `[CN-DUMP-` 开头的内容复制出来
5. 截图 + 复制的内容一起发到上面邮箱

### 翻译错误 / 缺字

截图 + 简单描述位置（比如"科技树 → 合金炉 → 效果栏"），直接发到邮箱。

## 技术说明

本汉化通过以下方式实现：

1. **字体替换**：用思源黑体（Source Han Sans）替换游戏自带的 monofonto，包含 1750+ 常用汉字
2. **文本映射**：`reverse_map.tsv` 表将游戏英文映射到中文
3. **运行时补丁**：修改 `Assembly-CSharp.dll` 注入自动替换逻辑，每秒扫描 UI 组件

**不修改任何游戏逻辑**，不影响存档、成就。
